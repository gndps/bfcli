# bfcli

A simple shell file sourcing manager. Place shell files in `~/.bfcli/src_files/`, run `bfcli update`, and a generated `.bflist` will source them all in your shell.

## Installation

### Quick install (curl | sh)

```sh
curl -fsSL https://raw.githubusercontent.com/gndps/bfcli/main/install.sh | sh
```

### From source

```sh
git clone https://github.com/gndps/bfcli
cd bfcli
cargo install --path .
```

## Setup

### 1. Initialize

```sh
bfcli init
```

This creates `~/.bfcli/` with a default `config.json` and an empty `src_files/` directory.

### 2. Add to your shell profile

```sh
bfcli appendrc eval
```

This detects the right rc file for your shell/OS (`~/.zshrc` for zsh, `~/.bash_profile` on macOS bash, `~/.bashrc` on Linux bash) and appends:

```sh
[ -f ~/.bfcli/.bflist ] && source ~/.bfcli/.bflist
```

It's idempotent — running it again won't add a duplicate line, even if an existing line refers to the same file via `~`, `$HOME`/`${HOME}`, or an absolute path instead of the exact string bfcli writes. To just preview the change without writing anything, use `bfcli appendrc shell`.

### 3. Place shell files in src_files/

```sh
# Example: add your aliases file
cp ~/my-aliases ~/.bfcli/src_files/aliases
cp ~/my-functions.sh ~/.bfcli/src_files/functions.sh
```

You can organize files in subdirectories — bfcli walks the tree recursively:

```
~/.bfcli/src_files/
  aliases
  functions.sh
  work/
    vpn.sh
    k8s
  personal/
    brew
```

### 4. Update the .bflist

```sh
bfcli update
```

## Commands

| Command | Description |
|---------|-------------|
| `bfcli init` | Create `~/.bfcli/` with default config and empty `src_files/` dir |
| `bfcli update` | Scan `src_files/`, write `~/.bfcli/.bflist`, print "Updated: N files" |
| `bfcli source` | Print help for the `source` subcommands (below) |
| `bfcli source print` | Update `.bflist` and print the sourceable script to stdout, for humans/debugging |
| `bfcli source shell` | Print the line to add to your shell rc file (no side effects) |
| `bfcli source eval` | Update `.bflist` and print the sourceable script, meant for `eval "$(bfcli source eval)"` |
| `bfcli appendrc` | Print help for the `appendrc` subcommands (below) |
| `bfcli appendrc shell` | Preview which rc file would be modified and what would be appended |
| `bfcli appendrc eval` | Detect the rc file and append the sourcing line if not already present |
| `bfcli appendrc eval --fast` | Same, but skips the existing-content check (can duplicate the line if run twice) |
| `bfcli files` | List all files that will be sourced |
| `bfcli config` | Open `~/.bfcli/config.json` in `$EDITOR` |
| `bfcli help` | Print help |

### eval mode

`bfcli source` never modifies your current shell by itself — a subprocess can't reach into its parent shell's environment. To pick up changes without restarting your shell, wrap it in `eval`:

```sh
eval "$(bfcli source eval)"
```

This re-scans `src_files/` on every call, unlike the static `.bflist` file that `bfcli appendrc eval` wires into your rc file.

## Configuration

`~/.bfcli/config.json`:

```json
{
  "extensions": ["", ".sh"]
}
```

| Value | Meaning |
|-------|---------|
| `""` | Source files with no extension (e.g. `aliases`, `functions`) |
| `".sh"` | Source files with `.sh` extension |
| `".bash"` | Source files with `.bash` extension |

Hidden files (filenames starting with `.`) are always skipped regardless of config.

To edit the config:

```sh
bfcli config
```

## The src_files directory

`~/.bfcli/src_files/` is just a regular directory — manage it however you like:

- **Git repo**: `cd ~/.bfcli/src_files && git init`
- **Symlinks**: `ln -s ~/dotfiles/shell ~/.bfcli/src_files`
- **Your dotfiles manager**: point it at `~/.bfcli/src_files/`

Files are sourced in alphabetical order, recursively. Subdirectory files come after files in the parent directory at the same level (depth-first alphabetical walk).

## How it works

1. `bfcli update` scans `~/.bfcli/src_files/` recursively
2. Filters files by configured extensions (skips hidden files)
3. Writes `~/.bfcli/.bflist` — a shell script of `source` commands
4. Your shell profile sources `.bflist` on startup

### .bflist format

```sh
# Generated by bfcli - do not edit manually
source /Users/me/.bfcli/src_files/aliases
source /Users/me/.bfcli/src_files/functions.sh
source /Users/me/.bfcli/src_files/work/k8s
```
